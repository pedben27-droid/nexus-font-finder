# NEXUS FONT FINDER v1.2 — Advanced Matching

## จุดเด่น
- ฐานข้อมูลฟอนต์ถาวรด้วย IndexedDB ใน Chrome / Edge
- เพิ่มฟอนต์ได้หลายไฟล์ หรือเลือกทั้งโฟลเดอร์ (TTF, OTF, WOFF, WOFF2)
- ส่งออก/นำเข้าฐานข้อมูล JSON เพื่อสำรองและย้ายเครื่อง
- นำเข้าภาพ Artwork PNG, JPG, WebP, SVG
- ปรับ threshold, กลับสี, padding และขนาดตัวอย่าง
- วิเคราะห์ silhouette, pixel overlap, projection แนวตั้ง/แนวนอน และสัดส่วนภาพ
- จัดอันดับคะแนน, กรองชื่อ, ดู preview, overlay, favorite และลบฟอนต์
- ทำงานในเครื่อง ไม่อัปโหลดไฟล์ขึ้นเซิร์ฟเวอร์

## วิธีใช้งาน
1. แตก ZIP
2. เปิด `index.html` ด้วย Chrome หรือ Edge
3. เพิ่มคลังฟอนต์ในหัวข้อ Font Database
4. นำเข้า Artwork แล้วพิมพ์ข้อความในภาพให้ตรงทุกตัว
5. ปรับ Threshold / Padding ตามลักษณะภาพ แล้วกดวิเคราะห์
6. คลิกผลลัพธ์เพื่อดูตัวอย่างและภาพซ้อนทับ
7. กดส่งออกฐานข้อมูลเพื่อสำรองฟอนต์เป็นไฟล์ JSON

## คำแนะนำเพื่อความแม่นยำ
- ใช้ภาพที่มีความละเอียดสูง ตัวอักษรคมชัด พื้นหลังเรียบ และไม่เอียง
- ครอปให้เหลือเฉพาะข้อความที่ต้องการเทียบ ไม่รวมโลโก้/ภาพประกอบ
- กรอกข้อความให้ตรง รวม uppercase/lowercase ตัวเลข เครื่องหมาย และเว้นวรรค
- ถ้าเป็นตัวอักษรสีอ่อนบนพื้นเข้ม ให้ลองเปิด “กลับสีภาพ”
- ปรับ Threshold จนตัวอักษรเป็นสีดำเต็มและพื้นหลังขาว
- แยกวิเคราะห์ทีละบรรทัดเมื่อ Artwork มีหลายบรรทัดหรือหลายขนาด

## ข้อจำกัดที่ต้องทราบ
- คะแนนเป็นการจัดอันดับเชิงภาพ ไม่ใช่ความน่าจะเป็นหรือการยืนยันชื่อฟอนต์
- การเทียบภาษาไทยใช้ภาพรวมของบรรทัดเป็นหลัก เพราะสระ/วรรณยุกต์เป็น glyph ที่อาจแยกชิ้นจากพยัญชนะ การให้คะแนนรายตัวอักษรแบบเชื่อถือได้ต้องเพิ่มระบบ segmentation/recognition เฉพาะภาษา
- ไม่รองรับ PDF/AI โดยตรงในรุ่นนี้: Export ภาพอ้างอิงเป็น PNG จาก Illustrator ก่อน
- ฟอนต์ใน IndexedDB อยู่ใน browser profile และเครื่องเดิม หากล้างข้อมูลเว็บไซต์/เบราว์เซอร์อาจหาย จึงควร export backup
- การอ่านฟอนต์บางชนิดอาจถูกจำกัดโดยเบราว์เซอร์
- Prototype นี้ยังไม่ใช่ Windows installer (.exe) หรือระบบ Cloud

## ข้อมูลส่วนตัว
ไฟล์ฟอนต์และ Artwork ประมวลผลในเครื่อง ไม่มีการส่งขึ้น server โดยแอปนี้
